# Portfólio de Análise de Dados - Matheus Alba

Portfólio de Análise de Dados com foco em Power BI e visualização de dados. Os projetos demonstram desenvolvimento de dashboards, modelagem de dados e geração de insights acionáveis para apoiar a tomada de decisão nos negócios.

---

## Projetos
